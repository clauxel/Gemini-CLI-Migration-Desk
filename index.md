# Gemini CLI Migration Desk

Audit Gemini CLI migration readiness before teams flip the switch.

Gemini CLI Migration Desk imports repositories, CLI configs, extension inventories, rollout owners, and policy notes, then turns migration risk into a signed evidence packet.

This is a public documentation project for Gemini CLI Migration Desk. The structure is modeled after the public documentation pattern used by [MiroFish](https://github.com/clauxel/MiroFish): a short front door, a clear reading order, practical guides, reference pages, and public-safe architecture notes.
