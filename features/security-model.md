# Security Model

## Public Repository Boundary

- Documentation only.
- No production source code.
- No credentials or API tokens.
- No customer records or private transcripts.
- No local deployment paths or account screenshots.

## Product-Specific Risks

- Review custom extensions before org-wide rollout.
- Keep private repository material out of public issues.
- Treat generated readiness scores as a review aid, not an approval substitute.
