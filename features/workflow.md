# Workflow

Gemini CLI Migration Desk imports repositories, CLI configs, extension inventories, rollout owners, and policy notes, then turns migration risk into a signed evidence packet.

## Repeatable Flow

1. Import repositories and Gemini CLI configuration.
2. Inventory extensions, policy files, and team ownership.
3. Flag blockers, risky diffs, and missing approvals.
4. Export a signed readiness packet for rollout review.

## Output Mindset

The useful artifact is not a marketing claim. It is evidence that a reviewer can inspect, export, and compare later.
