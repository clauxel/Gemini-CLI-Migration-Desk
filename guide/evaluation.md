# Evaluation Guide

Use this page to evaluate whether Gemini CLI Migration Desk fits a real workflow.

## What To Test

- Gemini CLI migration audit
- Gemini CLI extension inventory
- Gemini CLI policy review
- AI IDE migration checklist

## Expected Evidence

- Import repositories and Gemini CLI configuration.
- Inventory extensions, policy files, and team ownership.
- Flag blockers, risky diffs, and missing approvals.
- Export a signed readiness packet for rollout review.

## Risk Checks

- Review custom extensions before org-wide rollout.
- Keep private repository material out of public issues.
- Treat generated readiness scores as a review aid, not an approval substitute.
